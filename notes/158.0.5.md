## Nouveautés

- Palette de commandes (Ctrl+K) : toutes les actions, les onglets de tous les espaces, l'historique, les favoris et les onglets fermés
- Pipette à couleurs : récupère le code HEX, RGB, HSL ou OKLCH de n'importe quel pixel
- Vue partagée jusqu'à 4 pages, en grille ou en colonnes
- Onglets en haut : une barre d'onglets classique, au style d'Orbit
- Verrouillage d'Orbit avec Windows ou un code PIN (Ctrl+Alt+L), automatique après une inactivité
- Mode concentration (Ctrl+Maj+F) : la page seule
- Sessions : enregistre tes onglets sous un nom et restaure-les plus tard
- IA sur plusieurs onglets : résumé, comparaison ou question sur les pages choisies
- Raccourcis personnalisables pour chaque action
- Synchronisation des espaces et réglages avec Firefox Sync
- Export et import des réglages d'Orbit
- Notes sur les onglets

## Améliorations

- Paramètres plus clairs : chaque réglage s'explique, bouton « Rétablir » sur ce que tu as changé
- Page des raccourcis refaite, avec recherche
- Effacer les données d'un site, fermer les onglets en double, installer un site comme application
